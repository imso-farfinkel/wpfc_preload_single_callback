# Boas-vindas: estudos de lógica de programação
A lógica sustenta qualquer software. O trabalho é compreender um problema, dividi-lo em partes pequenas e ordenar essas partes de modo sistemático até a solução aparecer. Serve para quem começa a programar, sem depender de linguagem ou ferramenta.

Aqui reúno parte dos meus estudos de lógica em Python. O material fica organizado nas páginas do projeto:

1. Primeiros conceitos da lógica
2. Estruturas de dados
3. Orientação a objetos

Ah, e tem também vários algoritmos resolvidos em Python para praticar. Tomara que ajude nos seus estudos ;-)
